C Window Maker

Overlap two Cs. The red and the blue overlap in green, and the green shape is the window. Move, rotate and flip them, then save an SVG.

Drag a C to move it. Drag the round handle to rotate it (it snaps to 15 degrees; hold Shift to turn snapping off or on). Arrow keys nudge, [ and ] rotate, H and V flip.

Shape of the C

The built-in C is the ISACA-approved C from the brand guide's Visual Style page, with its straight slot and rounded corners. These two sliders start at its real values.

Use my own C shape

Paste the path data (the d value) of a single closed, filled shape, or load an SVG file with one path. Transforms inside the file are not applied. The shape is centered and sized to match the built-in C.
