# T7C — Portfolio Publishing (ISA Work)

**Session focus:** package your work so others can see it  
**Applied to:** ISA Foundation + design artifacts

## Five deliverables

1. **Live URL** — GitHub Pages or shared demo link  
2. **GitHub repo** — structured source  
3. **README** — goals, stack, how to run  
4. **Professional homepage** — who you are + what you built  
5. **Short presentation** — 2–3 minute walkthrough
